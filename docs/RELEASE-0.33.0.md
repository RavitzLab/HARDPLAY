# Hard Play 0.33.0

- Removed the At End / In order strip below transport. End behavior is shown inside the current deck; ordering mode is shown inside the next deck.
- Removed the colored playlist-name tape. A compact menu beside Setup Lock displays the saved playlist name, or Save playlist for an unsaved set. Rename remains available in that menu.
- Shuffle is available next to Repeat in Main, Mini, Nano and the menu-bar controller. Enabling it exits Repeat One and enables Next; the active state is visible.
- Volume opens in a themed child panel anchored to the left of its player window. At the display edge it stays visible against the left boundary instead of flipping to the right. It follows window movement and closes on outside click, minimization or app deactivation.
- Playlist toggles use the list-bullet icon; the redundant Edit Queue label is removed from Mini.
