# Hard Play 0.32.9

- Main and Mini use the same compact Repeat control on the right of the centered transport.
- Mini's separate seek/time strip is removed. Waveform seeking remains available in the decks and Nano.
- Main and Mini volume is opened from a speaker button on the left of transport, with a vertical native slider and percentage in a popover.
- Show Playlist is an icon-only list button with an accessible name and hover hint.
- Queue sorting: track number ascending/descending, name A–Z/Z–A, newest/oldest added, filename, format, reverse and random order. Sorting preserves current track/position and can be undone.
- Added timestamps persist with queue and playlist documents. Existing queues without timestamps retain their stored order as a fallback; historical addition dates cannot be reconstructed.
