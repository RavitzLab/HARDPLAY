# Hard Play 0.34.2

- Main and Mini: Crossfade moved into transport, immediately before Shuffle; new merging-arrows icon replaces the waveform symbol. The lower playlist toolbar no longer repeats Fade.
- Removed hold-to-seek. Each current deck has a small seek padlock immediately before its gain percentage. Click to unlock, then click/drag the waveform. Release, leaving the waveform, focus loss, track/window change, or global playback protection locks it again.
- An unused unlock expires after five seconds; beginning a drag cancels that idle timeout until release. Locked hover still shows time, without changing playback. NEXT remains inspection-only.
- Nano and menu-bar waveforms use the same explicit seek lock beside their remaining-time readout, preserving the Nano wheel layout.
