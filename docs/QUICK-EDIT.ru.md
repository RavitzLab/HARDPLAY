# Quick Edit

В строке трека нажмите ножницы или выберите правой кнопкой **Quick Edit…**. Редактор открывается отдельным окном, очередь остаётся на месте.

1. Выделите участок перетаскиванием прямо по аудиоволне. **⌘-перетаскивание** добавляет второй отдельный участок. **⌘-клик** добавляет или снимает выбор существующего фрагмента. Счётчик показывает число выбранных фрагментов и их общую длительность.
2. **Split at Cursor** разделяет дорожку по курсору; исходный файл не меняется. Масштаб меняется кнопками лупы, жестом увеличения или ⌘-прокруткой. Нижний ползунок перемещает видимую часть, **Height** меняет высоту дорожки. **Fit Selection / Fit All** возвращают удобный обзор.
3. Для точной границы перетащите край выделения, задайте **In / Out** ползунками или введите время в формате `0:15.250`. Enter применяет числовой ввод. Стрелки в активной аудиоволне двигают курсор на один сэмпл; Shift-стрелки — на 10 мс.
4. Переместите позицию прослушивания и нажмите **Mark In / Mark Out**, чтобы поставить точку в этом месте. **Full Track** выбирает всю дорожку. **Clear Selection** снимает выделение.
5. **Preview Selection** прослушивает выбранные участки по порядку. Удерживайте **Option** и перемещайте мышь над волной для поиска звука с позиции указателя. Прослушивание останавливается при отпускании Option, уходе мыши с волны или потере фокуса. У редактора своя громкость. При основном воспроизведении прослушивание доступно только через отдельно выбранный и доступный Preview Output; на совпадающем выходе оно блокируется.
6. Для нескольких выбранных фрагментов кнопка **Join & Save Copy…** склеивает их в один WAV в порядке расположения на дорожке, без пропущенных промежутков, и добавляет новый пункт после оригинала. **Join & Replace…** заменяет этим файлом исходный пункт очереди, сохраняя его идентичность и переход. Для одного фрагмента кнопки называются **Save as Copy… / Replace in Playlist…**. Замена звучащего пункта требует паузы.

Экспорт: WAV 32-bit float, исходная частота дискретизации и число каналов. Границы округляются до ближайшего аудиосэмпла. Исходный файл и уже существующие файлы не перезаписываются. Экспорт идёт в фоне ограниченными блоками, без загрузки всего аудио в память; его можно отменить.

**Undo / Redo** отменяет и возвращает изменение очереди. Сохранённый WAV остаётся на диске. Если во время экспорта пункт удалили или включили защиту, результат остаётся сохранённым файлом, а очередь не меняется; редактор показывает причину.

При замене сохраняется ID пункта для имеющихся назначений. Сохранение и открытие `.hardplay` поддерживает эту идентичность. Аудиоволна различает исходный и обработанный файл, даже если пункт очереди тот же.

Это редактор фрагментов одной исходной дорожки. Склейка не добавляет кроссфейд на стыках. Эквалайзер, нормализация, эффекты и объединение разных исходных файлов здесь пока не реализованы.

Проверка: `build/HARDPLAY.app/Contents/MacOS/HARDPLAY --clip-test`. Тест создаёт собственный стереофайл и проверяет точные отсчёты обрезки, длину, каналы, частоту, сохранность исходника, запрет перезаписи, отмену экспорта, Copy/Replace, Undo/Redo и сохранение плейлиста. Пользовательская музыка не проигрывается.

## Удаление тишины по краям

**Detect Edge Silence** анализирует начало и конец дорожки в фоне. Порог по умолчанию −60 dB, регулируется от −90 до −20 dB. Нажмите **Select Trimmed Audio**, прослушайте результат и сохраните копию либо замените пункт плейлиста. Паузы внутри музыки сохраняются. Очень короткие края (менее 100 мс) не обрезаются; перед звуком сохраняется защитный запас 20 мс. Полностью тихий файл отмечается отдельно. Для тихих вступлений и шумных записей подберите порог вручную; анализ ничего не удаляет без экспорта.
