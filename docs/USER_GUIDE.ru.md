# Hard Play — руководство пользователя

Руководство для нативного Mac-приложения, исходники **0.35.5**. Интерфейс на английском. Версия скачанного установщика указана в Releases и может отличаться.

## Быстрый старт

1. Перетащите аудио из Finder в плеер или открытый плейлист. В PATCH → Audio выберите Main Output.
2. Нажмите название трека, чтобы выделить его. Нажмите отдельную **Play** в строке либо транспорт плеера, чтобы начать воспроизведение.
3. Через **Modes** выберите поведение в конце: следующий трек или остановка. Repeat переключает один трек / весь плейлист / выключен. Shuffle включает случайный порядок.
4. В **Crossfade** задайте секунды и примените к одному переходу или всему плейлисту. Ноль — без наложения; начальное значение нового перехода — 2 секунды. Сохранённые значения не сбрасываются автоматически.
5. Откройте **Playlist Actions → Save Playlist** и сохраните сет.

## Основное управление

Play/Pause, Previous и Next управляют текущей очередью. Громкость открывает регулятор общего уровня. Две деки чередуют стороны по мере воспроизведения; **NOW** — текущий, **NEXT** — следующий. Во время кроссфейда проценты показывают усиление каждой деки, а не измеренный уровень сигнала.

Наведение на волну показывает время в данной точке. Для перемотки текущего трека разблокируйте маленький замок рядом с процентом, затем нажмите или протяните по волне. После жеста замок закроется; неиспользованная разблокировка истекает через пять секунд. Волна NEXT служит для просмотра: стартовую позицию задавайте через **Start at…** в действиях трека. Само наведение или выделение не должно запускать трек.

## Плейлист

- Кнопка списка показывает и скрывает очередь. Перетаскивайте трёхполосную ручку строки для изменения порядка.
- Правый клик или меню действий строки: Play, Preview, Duplicate, Rename, Quick Edit, Fade, Start at и удаление. Доступность зависит от блокировки и выбранных аудиовыходов.
- Дубликат — независимый пункт: название, переход и стартовая позиция могут отличаться, хотя исходный файл общий.
- Сортировка меняет порядок очереди. Сохраните плейлист после нужных изменений.
- В Playlist Actions находятся сохранение, открытие, новое имя, новый сет, удаление и добавление аудио. Удаление пункта не удаляет исходный аудиофайл. Удаление сохранённого плейлиста требует подтверждения.
- `.hardplay` хранит настройки и ссылки на аудио. Для переноса вместе с музыкой используйте Backup Package. Не публикуйте свои плейлисты в GitHub: они могут содержать локальные пути.

### Горячие клавиши

| Действие | Клавиши |
| --- | --- |
| Добавить аудио | ⌘O |
| Новый плейлист | ⌘N |
| Открыть плейлист | ⇧⌘O |
| Сохранить / Сохранить как | ⌘S / ⇧⌘S |
| Выделить всё | ⌘A |
| Копировать / Вырезать / Вставить | ⌘C / ⌘X / ⌘V |
| Дублировать выбранное | ⌘D |
| Удалить из очереди | ⌘Delete |
| Отменить / Вернуть | ⌘Z / ⇧⌘Z |
| PATCH | ⌘, |
| Main / Mini / Menu Bar | ⌘1 / ⌘2 / ⌘3 |
| Keyboard / MIDI | ⇧⌘M |
| Заблокировать управление | ⌘L |
| Выйти из приложения | ⌘Q |

Операции очереди работают в контексте плейлиста; при вводе текста стандартные сочетания редактируют текст. Для основных операций также есть Control-аналоги. Undo/Redo меняют очередь, но не удаляют уже экспортированные WAV.

## Окна и настройки

**Main** — большой плеер, **Mini** — компактный, **Nano** — настольный виджет с кольцом управления. Переход между ними использует один и тот же плеер. Меню-бар даёт компактный транспорт. Закрытие окна плеера скрывает приложение в меню-бар; Command-Q завершает процесс.

**PATCH** разделён на Audio, App, Playlists и Window. В Window отдельно выбираются параметры Main, Mini и Nano. Темы, Keyboard / MIDI, Backup и Web Viewer открываются из App. **Back to Player** и закрытие служебного окна возвращают тот плеер, из которого открыты настройки. Настройка Workspace определяет, будут панели внутри плеера или отдельными окнами.

## Темы, подсказки и защита

В **PATCH → App → Themes & Appearance** доступны Tape Blue, FOH, Tape Black, Stage, Cables, Minimal, Mono Console, Crew Tape и White. Можно менять цвета, прозрачность Main/Mini, размеры кнопок и текста, расстояния, скругления и текстуру. Введите имя и нажмите **Save Theme**: вариант появится в **My Themes**. То же имя обновляет сохранение, новое создаёт копию. Текущее оформление и личные темы сохраняются на этом Mac.

Вопрос включает подсказки при наведении. Их также можно включить в PATCH → App. Полный Lock защищает управление; удерживайте кнопку разблокировки **1,5 секунды**. Музыка при блокировке продолжается. Защита плейлиста/настроек и маленькие замки перемотки — отдельные механизмы.

## Аудиовыходы и предварительное прослушивание

В **PATCH → Audio** выберите **Main Output** для основного звука и **Preview Output** для прослушивания. Если выходы совпадают, одновременный Preview ограничен, чтобы не подмешивать его в основной звук. Убедитесь в фактической маршрутизации на своих устройствах до выступления.

Для MIDI/клавиш откройте **Keyboard / MIDI**, включите Map, выберите действие и подайте сигнал. Выключите Map для обычной работы; Esc отменяет ожидание. Поддерживаемые действия могут быть Trigger или Toggle, громкость — непрерывным MIDI CC. Системные сочетания могут конфликтовать с другими программами; проверяйте свои назначения.

## Редактор, просмотр и резерв

- [Quick Edit](QUICK-EDIT.ru.md): выделение, обрезка, соединение участков и удаление тишины по краям.
- [Web Viewer](WEB-VIEWER.ru.md): просмотр состояния и очереди в локальной сети, без управления и передачи аудио.
- [Backup Setup](BACKUP-SETUP.ru.md): перенос музыки и проверка совпадения сетов. Это подготовка резерва, не автоматический синхронный запуск или переключение звука.

Офлайн-веб-плеер — [отдельная версия](../web/README.md) с другим набором возможностей. Он не разделяет автоматически библиотеку Mac-приложения.
