# Hard Play 0.33.2

- Centered playlist name in the toolbar with Fade and setup/window controls.
- Replaced the permanent Save/Rename/New/Delete/Add row with one ellipsis-and-chevron button on the right.
- Playlist Actions opens in a themed child window to the right of the player, containing Save, Rename, New, Delete, Add, Open, Save As, Recent playlists and window/setup controls. Closing it or clicking outside hides it. Near the screen edge it stays within the visible display.
- Main Lock now uses the same compact open/closed lock icon as Mini; unlocking still requires holding for 1.5 seconds.
- Volume and Playlist Actions share attached-panel positioning and lifecycle handling, using their respective left/right sides.
