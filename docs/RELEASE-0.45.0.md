# HARDPLAY Beta 5 — только для Mac

Версия 0.45.0 · macOS 14+ · Apple Silicon (M1 и новее).

## Скачать и начать

1. Откройте DMG и перетащите HARDPLAY.app в «Программы».
2. Перетащите музыку в плеер или плейлист.
3. PATCH → Audio: выберите Main Output и отдельный Preview Output.
4. Настройте переходы и сохраните сет.
5. Для двух Mac создайте пару в Timecode & Backup, синхронизируйте сет и включите Linked Playback на обоих.

## Главное

- Отдельный Preview на второй аудиовыход.
- Кроссфейды для перехода или всей очереди.
- Аудиоредактор: обрезка, выделение и соединение фрагментов, удаление тишины по краям, экспорт WAV.
- Main, Mini, Nano и меню-бар с индикацией Main / Preview.
- Синхронизация настроек сета и связанное Play/Pause, переходы и перемотки между двумя Mac по локальной сети.
- Modular Grid по умолчанию во всех окнах.

DJ Gear недоступен. Сайт предоставляет установщик Mac; веб-плеер закрыт. Web Viewer остаётся просмотром состояния.

## Перед работой

Бета подписана ad-hoc, без нотарификации Apple. При блокировке первого запуска проверьте источник и используйте обычное «Конфиденциальность и безопасность → Всё равно открыть». Не отключайте защиту macOS.

Аудиофайлы должны быть на обоих Mac. Выходы и громкость локальные; автоматического переключения аудиовыхода при сбое нет. Сетевые команды не гарантируют синхронизацию физических выходов до сэмпла. Проверьте сет, аудиокарту и резервный компьютер перед выступлением.
