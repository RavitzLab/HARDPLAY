# HARDPLAY Beta 5 - Mac only

**0.45.0 | macOS 14+ | Apple Silicon**

## Download and start

Open the DMG, drag **HARDPLAY.app** into **Applications**, then drop your audio into the player. Open **PATCH > Audio** to check Main Output and choose a separate Preview Output.

[Quick start](https://github.com/RavitzLab/HARDPLAY/blob/main/docs/QUICKSTART.md)

## What is included

- **Separate Preview:** audition tracks on a second audio output without sending them to Main.
- **Crossfades:** set transitions individually or across the playlist.
- **Audio editing:** waveform zoom, trim, region selection/join, edge-silence detection and WAV export.
- **Main, Mini and Nano:** three views of the same player, plus menu-bar controls with Main/Preview indication.
- **Linked Macs:** pair Primary A and Backup B, sync playlist settings, and share Play/Pause, track changes and seeks with Linked Playback enabled on both.
- **Modular Grid:** the default across player windows, settings and Web Viewer.

DJ Gear is unavailable. The website provides Mac downloads; browser playback and PWA installation are retired. Web Viewer remains a read-only status display.

## Beta notes

The app is ad-hoc signed and not notarized by Apple. If macOS blocks the first launch, verify the source and use **System Settings > Privacy & Security > Open Anyway**. Do not disable macOS security.

Audio files must exist on both Macs; set sync does not transfer audio. Output routing and volume remain local. Linked control is not sample-accurate physical audio synchronization or automatic output failover. Test your playlist, interface and network before live use.
