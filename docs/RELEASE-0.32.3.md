# Hard Play 0.32.3

- Replace the Restart button in Main/Mini with a shared Repeat control. Cycle Off → One → All, or select directly with its context menu. The same playback mode is reflected in the compact menu-bar player. Resume remains available; existing Restart mappings are retained.
- Menu-bar player gains the decoded waveform with played-position indication, click/drag seeking and double-click playback, plus a master-volume speaker/slider and an explicit Open Main Player icon.
- Return the question-mark control to Main/Mini and compact players. It toggles the existing anchored hover hints without opening PATCH; active styling and accessibility state show whether hints are enabled.
- Nano also gains a compact master-volume slider and question-mark toggle.
