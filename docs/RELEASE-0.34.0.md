# Hard Play 0.34.0

- Main and Mini: Play stays exactly at the horizontal window center. Previous and Next are symmetric; Repeat, Shuffle and Open Playlist form the right group. Volume stays on the left.
- Open Playlist moved from the header to the far right of transport. Playlist Actions moved into the lower playlist toolbar.
- Added Mono Console, Crew Tape and Signal White themes, using system monospaced typography and sparse native vector details. No new raster textures, fonts, animations or dependencies.
- Nano wheel layout is unchanged. Waveform seeking still requires a 1.5-second hold.
