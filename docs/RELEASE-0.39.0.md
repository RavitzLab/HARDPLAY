# Hard Play 0.39.0 — More themes and a clearer header

- Eight additional concept presets: Hard Minimal, Brutalist Play, Premium Dark, Digital Underground, Grid Motion, Noir Vinyl, Rave Terminal and Steel Play. Twenty-one built-in themes in total; existing custom themes remain available.
- Main and Mini share the original centered HARDPLAY wordmark, red while playing. Minimize and Hints move left so controls do not cover the logo.
- Utility navigation uses a compact arrow-only Back button, with a tooltip and accessible name.
- Built-in White and legacy Signal White have softer grey backgrounds/panels; light decks no longer use a bright white gradient.
- Added nine renamed OFL-derived faces across Hardplay Sans, Hardplay Grid and Hardplay Mono. Concept themes no longer look up commercial fonts. See docs/CONCEPT-THEMES.md for palette and typography substitutions. No continuous decorative animation or new runtime dependency.
