# Установка Hard Play на Mac

## Готовое приложение

1. Откройте [Releases RavitzLab/HARDPLAY](https://github.com/RavitzLab/HARDPLAY/releases/latest) и скачайте **HARDPLAY-…-macOS-arm64.dmg** или ZIP. Вход в GitHub для публичного скачивания не нужен.
2. Требования готового пакета: **macOS 14 Sonoma или новее, Apple Silicon (M1/M2/M3 и новее)**. Универсального установщика для Intel нет.
3. В DMG перетащите **HARDPLAY.app** в **Applications / Программы**. Для ZIP распакуйте файл и перенесите приложение туда же.
4. Откройте Hard Play из Программ или Spotlight. Добавьте музыку кнопкой добавления или перетащите файлы из Finder в плеер либо открытый плейлист.
5. Проверьте **PATCH → Audio → Main Output**, затем нажмите Play. Выделение трека само по себе не запускает звук.

Сборка подписана локально (ad-hoc), без Apple notarization. Если macOS блокирует первый запуск, убедитесь, что файл скачан из нужного релиза, и используйте **System Settings → Privacy & Security → Open Anyway**. Не отключайте Gatekeeper. При сомнениях сверьте SHA-256 со скачанным файлом `.sha256`.

## Обновление и выход

Закройте приложение через **Command-Q**, затем замените его в Программах новой версией. Перед обновлением поставьте воспроизведение на паузу и сохраните сет. Закрытие окна плеера оставляет приложение в меню-баре. Закрытие PATCH, Themes и других служебных окон возвращает плеер; там же есть **Back to Player**.

Плейлисты и исходное аудио храните отдельно от приложения. Файл `.hardplay` содержит ссылки, порядок и настройки, а не копии музыки. Перед переносом на другой Mac подготовьте [Backup Package](BACKUP-SETUP.ru.md).

## Веб-версия

У веб-плеера отдельная [инструкция](../web/README.md). Для установки в Dock используйте меню браузера; приложение должно открываться через HTTPS либо localhost. Сначала загрузите оболочку и дождитесь кэширования каждого трека. Перед выступлением проверьте всю очередь без интернета. Очистка данных сайта удаляет кэш; библиотека браузера не синхронизируется с нативным приложением.

## Если не работает

- **Файл не играет:** проверьте, что он полностью скачан и доступен локально. Поддержка кодеков зависит от macOS. Сообщение об ошибке не означает, что звук можно восстановить из пустого файла.
- **Нет звука:** проверьте Main Output, системную громкость и устройство. Preview использует свой выход.
- **Не видно окна:** откройте Hard Play из меню-бара или запустите приложение из Программ повторно.
- **Скачанный интерфейс отличается от инструкции:** README отдельно указывает версию исходников и доступного установщика.
