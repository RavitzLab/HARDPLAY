# HARDPLAY Beta 5

Рабочая предварительная версия 0.44.0 для macOS 14+ на Apple Silicon.

## Что входит

- Main, Mini, Nano и управление из строки меню с общим плейлистом.
- Preview на отдельном аудиовыходе: клик — Play/Pause, удержание 0,5 с — Stop; состояние показано внутри значка наушников.
- В логотипе треугольник PLAY красный при основном воспроизведении, HARD — при Preview.
- Перенос Main/Mini/Nano за логотип и пустую область заголовка.
- Размер Nano: Small / Optimal / Large в левой панели, открываемой нажатием на левый край дисплея.
- Исправлены цикл автоматического изменения размеров, нагрузка при Preview и сбой отрисовки DJ-кнопок.
- Темы, редактирование и сохранение плейлистов, аудиоредактор, настройки аудиовыходов, клавиатуры/MIDI, Web Viewer, Timecode & Backup.

## Установка

Откройте DMG, перенесите HARDPLAY.app в «Программы». Закройте предыдущую копию перед заменой. ZIP содержит то же приложение; файл SHA256 позволяет проверить скачивание.

## Ограничения беты

Приложение подписано локальной ad-hoc подписью и не нотарифицировано Apple. DJ остаётся экспериментальным, его развитие отложено. Синхронизация и переключение резервного компьютера требуют проверки с вашим оборудованием; локальные тесты не подтверждают точность физических аудиовыходов.

Перед выступлением проверьте свой сет и сохраните резервную копию плейлиста.
