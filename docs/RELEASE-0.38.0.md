# Hard Play 0.38.0 — Four concept themes

Added Studio Precision, Modular Grid, Timecode Core and Shadow System to PATCH → Themes & Appearance, alongside the existing nine presets. They share the same Main, Mini, Nano and menu-bar controls and preserve the original HARDPLAY logo.

Each preset defines panel/surface colors, waveform, grid/borders, secondary text, typography, spacing and corner treatment. New colors can be customized and saved in My Themes. Studio uses IBM Plex Sans/Mono; Modular uses Space Grotesk/Space Mono; Timecode uses Inter Tight/JetBrains Mono. These six fonts are bundled with OFL licenses (about 1.6 MiB uncompressed). Shadow uses installed Satoshi when available, otherwise macOS system sans/mono. Additional secondary sans faces and proprietary fonts are not redistributed.

New surfaces use flat fills and sparse static vector marks, with no large raster background, shader or continuous decorative animation. Existing playback and protection behavior is unchanged. See docs/CONCEPT-THEMES.md for palettes, states, configurations and font substitutions.
