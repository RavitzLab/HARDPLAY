# Hard Play 0.28.9

- Nano's invisible left display edge now toggles a separate animated locks panel outside the player face, sliding left on open and back on close.
- The panel follows the Nano window as it moves/resizes and hides when leaving Nano. Near the left screen edge, Nano temporarily makes room; closing restores its original position if it has not moved since.
- Lock controls only from the slide-out panel. The large Lock control is removed from the wheel.
- The bottom wheel button unlocks controls only after a continuous three-second hold. Early release cancels. In the unlocked state this button does not lock the player.
- Main and Mini retain their existing top Lock controls.
