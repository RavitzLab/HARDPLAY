# Hard Play 0.32.6

- NEXT waveforms are inspection-only: clicking, dragging or double-clicking cannot seek, start playback or store a hidden start offset.
- The current/outgoing waveforms retain scrubbing; hover timestamps remain available on NEXT.
- Playlist track menus now offer **Start at…**. Enter seconds or `m:ss`, then choose Start to explicitly play from that point. Cancel changes nothing; negative and invalid times are rejected.
- Removed the Resume button from Main and Mini. The configured On Play behavior remains available in playback settings.
