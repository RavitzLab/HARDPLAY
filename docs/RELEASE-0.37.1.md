# Hard Play 0.37.1 — Direct PATCH navigation

Selecting Themes & Appearance, Keyboard & MIDI, Timecode & Backup or Web Viewer in PATCH now immediately shows that tool in the same PATCH content area. The intermediate Open page and extra utility-window launch are removed from this navigation path. The sidebar stays visible, and each tool retains its own scrolling.

Embedded Keyboard & MIDI omits the minimize action for the separate mapping window. Mapping learning stops when leaving that section. PATCH restores a suitable minimum width for the sidebar and embedded tools. Theme changes still preview in the player immediately.

Standalone tools remain available through their existing application entry points. Playback, audio routing and linked synchronization are unchanged from 0.37.0. This update does not start Web Viewer sharing or create a backup connection automatically.
