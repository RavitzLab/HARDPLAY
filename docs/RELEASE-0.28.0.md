# Hard Play 0.28.0 — Blue & White / Playback Modes

- New Blue & White theme: white surfaces, dark blue text, blue active controls and softer blue next-deck styling. Native menus and fields use light appearance. Existing stage themes remain selectable; the previous theme data is backed up on first migration.
- Playback Modes opens from the Modes button or the left edge beside the decks. Main uses a leading sidebar; Mini uses a compact expandable block. Closing it restores the full player area. No separate window is created.
- Modes groups At End (Next/Stop), On Play (Restart/Resume), optional stop-before-end timing, and Off/3s/6s crossfades. Crossfade controls affect the current track's outgoing transition, with an explicit Apply to All action. Row-specific fades and Undo remain supported.
- Setup protection is visible and reversible within Modes. Full controls lock leaves the drawer read-only; PATCH remains the entry for unlocking controls.
- The old row of compound policy icons is replaced by a compact text summary. Symbols in Modes use familiar transport conventions with visible labels. Hover explanations continue in the optional fixed top hint strip.
- A paused current deck now says PAUSED. Main, Mini, playlist, PATCH and Pocket use the new palette; saved audio, queues and transport positions are retained.

macOS 14+, Apple Silicon. Ad-hoc signed, not notarized. Native update; hosted web edition unchanged.
