01 / CUE

Отдельный Preview

Основной звук — в систему, прослушивание — на второй аудиовыход. Проверяй следующий трек, не отправляя его в зал.

02 / TRANSITION

Кроссфейд под твой сет

Настраивай длительность перехода для каждого трека или всей очереди. Доступны переход без фейда, автостоп, Repeat и Shuffle.

03 / EDIT

Быстрый аудиоредактор

Приближай волну, выделяй и обрезай фрагменты, соединяй участки и убирай тишину по краям. Сохраняй результат отдельным WAV; исходный файл сохраняется.

04 / LINK

Два Mac. Один сет.

Соедини Primary A и Backup B по локальной сети, синхронизируй порядок и настройки сета. Включи Linked Playback на обоих: Play/Pause, переходы и перемотки передаются между плеерами.

ONE PLAYER / THREE SIZES

Main. Mini. Nano.

Полный экран работы с очередью, компактное окно или маленький плеер поверх рабочего стола. Один сет и общее управление.

READY IN A FEW STEPS

Быстрый старт

  1. Установи. Открой DMG и перетащи HARDPLAY.app в «Программы».
  2. Добавь музыку. Перетащи аудио в плеер или плейлист. Выбор строки не запускает звук — нажми Play.
  3. Проверь выходы. PATCH → Audio: выбери Main Output и отдельный Preview Output.
  4. Подготовь сет. Расставь треки, настрой переходы и сохрани плейлист.
  5. Подключи резервный Mac. Загрузи одинаковые аудиофайлы на оба, создай пару в Timecode & Backup, синхронизируй сет и включи Linked Playback на обоих.

Перед выходом на сцену: проверь весь сет, аудиокарту и сетевое соединение. Совместное управление не заменяет аппаратный аудиокоммутатор: автоматическое переключение выхода при сбое не реализовано. Аудиовыходы и громкость остаются локальными; сами аудиофайлы по сети не передаются.

Бета подписана ad-hoc, без нотарификации Apple. При блокировке первого запуска проверь источник файла и открой «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть». Отключать защиту macOS не нужно.
